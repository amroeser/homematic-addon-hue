# Verhaltenskodex

## Projekt

„Hue für HomeMatic“ wird von einem einzelnen Maintainer gepflegt und unter der [GPL-3.0](LICENSE) veröffentlicht. Die Weiterentwicklung richtet sich nach dem eigenen Bedarf.

## Beiträge

Beiträge sind als Pull Request willkommen. Über die Übernahme entscheidet der Maintainer.

Ein Pull Request sollte:

- beschreiben, was er ändert und warum
- die Tests bestehen (`python3 test/test_addon.py`)
- auf Tcl 8.2 bis 8.6 laufen, siehe [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- keine App-Keys, Session-IDs oder persönlichen Daten enthalten

Sicherheitslücken werden nicht öffentlich gemeldet, sondern wie in [SECURITY.md](SECURITY.md) beschrieben.

## Umgang

Diskussionen bleiben sachlich und respektvoll. Beleidigungen, Belästigung, Diskriminierung, Spam und das Veröffentlichen privater Daten Dritter sind nicht erlaubt. Beiträge, die dagegen verstoßen, werden geschlossen oder entfernt.
